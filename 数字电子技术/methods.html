📋 方法汇总——全课程分析方法一览

本文汇总数字电子技术课程中出现的所有分析、设计和转换方法，按章节排列。

第1章 数字逻辑概论

1. 数制转换方法

十进制 → 二进制（整数）：辗转相除法。将十进制数连续除以2，直至商为零，余数从低位到高位排列。

十进制 → 二进制（小数）：基数乘法。每次除去上次所得积中的整数再乘以2，直到满足误差要求。

2. 真值表 ↔ 逻辑表达式

真值表 → 表达式：取F=1的行，每行写成一个乘积项（变量1取原变量、0取反变量），全部相加。

表达式 → 真值表：列出所有输入组合，逐一代入表达式计算输出。

3. 真值表 ↔ 逻辑图

真值表 → 逻辑图：真值表→表达式→化简→逻辑符号连接。

逻辑图 → 真值表：逐级写表达式→化简→代入所有输入组合。

第2章 逻辑代数与硬件描述语言

1. 逻辑代数化简法

方法依据说明
并项法A + A = 1将两项合并为一项，消去一个变量
吸收法A + AB = A吸收多余乘积项
消去法A + AB = A + B消去多余因子
配项法A = A(B+B)通过配项简化

2. 卡诺图化简法

步骤：

  • 将逻辑函数写成最小项表达式
  • 按最小项表达式填卡诺图，含最小项的方格填1，其余填0
  • 合并相邻的1方格圈成一组（包围圈），每组含2ⁿ个方格
  • 将所有包围圈对应的乘积项相加

无关项处理：无关项的值可取0或1，根据使函数尽量简化而定。

3. 最小项与最大项表达式

最小项 Σm最大项 ΠM
看F=1的项F=0的项
变量=0反变量原变量
变量=1原变量反变量
连接相加（或）相乘（与）

4. 三大基本规则

代入规则：用函数式代入等式中的所有A，等式仍成立。

反演规则：·⇔+，0⇔1，原⇔反，得到反函数。

对偶规则：·⇔+，0⇔1，变量不变，得到对偶式。等式两边对偶后仍相等。

第4章 组合逻辑电路

1. 组合逻辑电路分析方法

  • 由逻辑图写出各输出端的逻辑表达式
  • 化简和变换逻辑表达式
  • 列出真值表
  • 根据真值表确定逻辑功能

2. 组合逻辑电路设计方法

  • 逻辑抽象：确定输入、输出变量，定义逻辑状态
  • 根据逻辑描述列出真值表
  • 由真值表写出逻辑表达式
  • 简化和变换逻辑表达式，画出逻辑图

3. 竞争冒险消除方法

  • 发现并消除互补变量
  • 增加乘积项，避免互补项相加
  • 输出端并联电容器（慢速工作时）

第6章 时序逻辑电路

1. 同步时序电路分析方法

  • 了解电路组成（输入、输出、触发器类型）
  • 写出输出方程、各触发器的激励方程
  • 将激励方程代入特性方程得状态转换方程
  • 列出状态转换表或画出状态转换图、波形图
  • 确定逻辑功能

2. 同步时序电路设计方法

  • 根据逻辑功能建立原始状态转换图/表
  • 状态化简——合并等价状态
  • 状态编码（状态分配）
  • 选择触发器类型
  • 求出激励方程和输出方程
  • 画出逻辑图并检查自启动能力

3. 异步时序电路分析方法

分析时必须考虑各触发器的时钟信号作用情况，每次状态转换从输入信号能触发的第一个触发器开始逐级确定。

4. 构成任意进制计数器的方法

  • 反馈清零法：利用异步清零端，跳过M-N个状态
  • 反馈置数法：利用同步置数端，跳过M-N个状态

第10章 模数与数模转换

1. DAC（数模转换）方法

倒T形电阻网络DAC：电阻仅R和2R两种，各支路电流按2的整数倍递减，输出电压与输入二进制数成正比。

权电流型DAC：各支路权电流不受开关导通电阻和压降影响，提高转换精度。

2. A/D转换的四个过程

取样 → 保持 → 量化 → 编码

采样定理：fs ≥ 2fimax，采样频率至少为输入信号最高频率的两倍。

3. ADC（模数转换）三种类型

类型速度精度特点
并联比较型最快（10ns~1μs）一般电路复杂，位数越多越复杂
逐次逼近型适中（几μs~100μs）高速度与复杂度平衡好
双积分型慢（几百μs~几ms）高抗干扰能力最强

4. 量化方式

  • 只舍不入：不足一个量化单位的部分舍弃，最大量化误差 = Δ
  • 四舍五入：不足半个量化单位舍弃，≥半个量化单位按一个处理，最大量化误差 = Δ/2
