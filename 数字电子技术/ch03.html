第3章 逻辑门电路

第4章 →

📌 教学基本要求

  • 了解半导体器件的开关特性。
  • 熟练掌握基本逻辑门（与、或、与非、或非、异或门）、三态门、OD门（OC门）和传输门的逻辑功能。
  • 学会门电路逻辑功能分析方法。
  • 掌握逻辑门的主要参数及在应用中的接口问题。

📖 逻辑门电路概述

逻辑门：实现基本逻辑运算和常用逻辑运算的单元电路。

逻辑门电路的分类

  • 分立门电路：二极管门电路、三极管门电路
  • 集成电路：
    • MOS门电路：PMOS、NMOS、CMOS
    • TTL门电路
    • BiCMOS门电路
🔑 核心思想：逻辑变量取值0或1，对应电路中电子器件的"闭合"与"断开"。
MOS管或BJT管可以作为开关。

3.1.2 开关电路——单管开关基础

逻辑门电路的基础是半导体器件的开关特性。单个晶体管（MOS管或BJT管）可以等效为一个受电压控制的电子开关。

逻辑变量取值0或1，对应电路中电子器件的"闭合"与"断开"。

3.2.1 MOS管及其开关特性

CMOS门电路是以MOS管为开关器件。

MOS管的分类

  • N沟道增强型
  • P沟道增强型
  • N沟道耗尽型
  • P沟道耗尽型

N沟道增强型MOS管的工作原理

（1）vGS 控制沟道的导电性：

  • vGS = 0, vDS ≠ 0 → 等效背靠背连接的两个二极管，iD ≈ 0
  • vGS > 0 → 建立电场 → 反型层 → vDS > 0, iD ≠ 0
  • 沟道建立的最小 vGS 值称为开启电压 VT

（2）vGS 和 vDS 共同作用：

  • vGS > VT, vDS > 0：靠近漏极的电压减小
  • vDS 增加 → iD 随 vDS 增加几乎成线性增加
  • 当 vDS 继续增加 → vGD = (vGS - vDS) ≤ VT → 漏极处出现夹断
  • 继续增加 vDS → 夹断区域变大，iD 饱和

MOS管的三个工作区

工作区条件特点
截止区vGS < VTiD ≈ 0，MOS管断开
可变电阻区vGS > VT, vDS 较小iD 随 vDS 线性增加，rds 为受 vGS 控制的可变电阻
恒流区（饱和区）vGS > VT, vDS 较大iD 基本不变（饱和）

其他类型的MOS管

（1）P沟道增强型MOS管：

  • 结构与NMOS管相反
  • vGS、vDS 电压极性与NMOS管相反
  • 开启电压 VT 为负值

（2）N沟道耗尽型MOS管：

  • 绝缘层掺入正离子，使衬底表面形成N沟道
  • vGS 可以是正值、零或负值
  • vGS 达到某一负值 vP，沟道被夹断，iD = 0

MOS管开关电路

MOS管相当于一个由 vGS 控制的无触点开关。

• 当 vI 为低电平（vI < VT）：MOS管截止，相当于开关"断开"，输出为高电平。

• 当 vI 为高电平（vI > VT）：MOS管工作在可变电阻区，相当于开关"闭合"，输出为低电平。

MOS管开关电路的动态特性

由于MOS管栅极、漏极与衬底间电容，栅极与漏极之间的电容存在，电路在状态转换之间有电容充、放电过程。输出波形上升沿、下降沿变得缓慢。

3.2.2 CMOS反相器（双管互补）

CMOS反相器由一个NMOS管（TN）和一个PMOS管（TP）互补构成。

工作原理

vIvGSNvGSPTNTPvO
0 V0 V−5 V截止导通5 V
5 V5 V0 V导通截止0 V

CMOS反相器的重要特点

  • 第一：无论vI是高电平还是低电平，TN和TP中总是一个导通而另一个截止。CMOS反相器的静态功耗几乎为零。
  • 第二：MOS管导通电阻低，截止电阻高。使充、放电时间常数小，开关速度更快，具有更强的带负载能力。
  • 第三：MOS管的 IG ≈ 0，输入电阻高。理论上可以带任意同类门，但负载门输入杂散电容会影响开关速度。

3.4 类NMOS门电路（单管下拉）

MOS集成电路分为PMOS、NMOS和CMOS。

NMOS比PMOS速度快。CMOS有静态功耗低、抗干扰能力强等诸多优点成为主流器件。但CMOS电路增加一个输入端必须增加一个PMOS和一个NMOS管，在某些希望芯片面积小的应用，仍采用NMOS。

类NMOS电路可与CMOS电路相匹配。

类NMOS反相器

  • 当 vI = 0：NMOS管截止，PMOS管导通，输出高电平。
  • 当 vI = VDD：NMOS管和PMOS管均导通，NMOS管比PMOS管导通电阻小很多，输出低电平。

即：一个NMOS管作为下拉驱动，一个PMOS管作为上拉负载（非互补结构）。

3.5 TTL逻辑门电路（BJT单管开关）

3.5.1 BJT的开关特性

BJT相当于受 vI 控制的电子开关。

• vI = 0 V 时：iB ≈ 0，iC ≈ 0，vO = VCE ≈ VCC，c、e极之间近似于开路（截止）。

• vI = 5 V 时：iB ≈ iBS，vO = VCE ≈ 0.2 V，c、e极之间近似于短路（饱和导通）。

BJT的开关时间

  • 开通时间 ton（= td + tr）：从截止到导通所需的时间。
  • 关闭时间 toff（= ts + tf）：从导通到截止所需的时间。

BJT饱和与截止两种状态的相互转换需要一定的时间才能完成。

TTL反相器的基本电路

TTL反相器由三部分组成：

  • 输入级：T1和电阻Rb1组成，用于提高电路的开关速度。
  • 中间级：T2和电阻Rc2、Re2组成，从T2的集电结和发射极同时输出两个相位相反的信号，作为T3和T4输出级的驱动信号。
  • 输出级：T3、D、T4和Rc4构成推拉式输出级，用于提高开关速度和带负载能力。

TTL反相器的工作原理

  • 输入为低电平（vI = 0.2 V）：T1深度饱和，VB1 = 0.9 V；T2、T3截止，T4、D导通。输出为高电平。
  • 输入为高电平（vI = 3.6 V）：T2、T3饱和导通，T1处于倒置的放大状态，T4和D截止。输出为低电平（vO = VCES3 = 0.2 V）。

抗饱和TTL门电路

采用肖特基势垒二极管（SBD）限制BJT导通时的饱和深度。SBD导通电压为0.4 V，使BJT的c、e间正偏电压钳位在0.4 V，而不进入深度饱和。

💡 单管门电路基础概念总结

🔘 MOS管作开关

MOS管相当于一个由vGS控制的无触点开关。

截止 → 断开；导通（可变电阻区）→ 闭合。

🔘 BJT作开关

BJT相当于受vI控制的电子开关。

截止 → 开路；饱和 → 短路（vCE ≈ 0.2 V）。

🔘 CMOS反相器

NMOS + PMOS 互补，一个导通另一个截止。

静态功耗几乎为零。

🔘 类NMOS

NMOS管作下拉 + PMOS管作上拉负载。

芯片面积小，适用于某些特定场合。
