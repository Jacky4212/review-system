555 9.4 555定时器

概述

555定时器是一种应用方便的中规模集成电路，广泛用于信号的产生、变换、控制与检测。有双极性和CMOS之分。

🎯 作用：广泛用于信号的产生、变换、控制与检测。
🔧 能完成的功能：
① 波形变换与整形——将正弦波、三角波等变换为矩形脉冲；对受干扰的波形进行整形
② 精确定时——产生固定宽度的脉冲（单稳态模式，tw≈1.1RC）
③ 产生脉冲波形——无需外加触发信号，自动产生矩形波（多谐振荡模式）
④ 幅度鉴别——检测输入信号是否超过设定的阈值电平

电路结构

555定时器内部由以下五部分组成：

  1. 电阻分压器——三个等值电阻串联，提供参考电压（2/3 VCC 和 1/3 VCC）
  2. 电压比较器——两个比较器C1和C2
  3. 基本SR锁存器
  4. 输出缓冲反相器
  5. 集电极开路输出三极管

三种典型应用

1. 用555组成施密特触发电路

将阈值输入端（TH）和触发输入端（TR）连在一起作为信号输入端。

  • 正向阈值电压 VT+ = 2/3 VCC
  • 负向阈值电压 VT- = 1/3 VCC
  • 回差电压 ΔVT = VT+ − VT- = 1/3 VCC

应用：波形变换、波形整形与抗干扰、幅度鉴别。

2. 用555组成单稳态电路

  • 稳态：输出为0。
  • 触发：外加触发信号（TR < 1/3 VCC），电路翻转到暂稳态，输出为1。
  • 暂稳态持续时间（由RC决定）：
tw = RC · ln3 ≈ 1.1 RC

3. 用555组成多谐振荡电路

无需外加触发信号，电路自动产生矩形脉冲波。

充电时间（高电平）

tpH ≈ 0.7 (R1 + R2) C

放电时间（低电平）

tpL ≈ 0.7 R2 C

振荡周期

T = tpH + tpL ≈ 0.7 (R1 + 2R2) C

通过改变RA和RB的比值，可以调节占空比。

📐 三种应用实例

实例一：施密特触发器——波形整形

场景：一个受干扰的正弦信号，变成干净的矩形脉冲。

接线：TH和TR连在一起接输入信号，5脚（CV）悬空或接滤波电容。

工作过程：
• 输入从0上升 → 超过 2/3 VCC → 输出翻转为低电平
• 输入从VCC下降 → 低于 1/3 VCC → 输出翻转为高电平
• 回差电压 ΔVT = 1/3 VCC 扛住噪声，防止抖动

实例二：单稳态电路——触摸延时灯

场景：按一下按钮，灯亮一段时间自动灭。

接线：TR接按钮（触发信号），TH和DIS连到外接RC，R一端接VCC，C一端接地。

工作过程：
• 稳态：输出为0，灯灭
• 触发：按下按钮 → TR < 1/3 VCC → 输出翻转为1，灯亮；放电管截止，电容经R充电
• 自动返回：电容电压充到 2/3 VCC → 输出翻回0，灯灭；放电管导通，电容放电
• 延时时间仅取决于RC参数：tw ≈ 1.1 RC
💡 实测计算：R = 100kΩ，C = 100μF → tw ≈ 1.1 × 100×103 × 100×10−6 ≈ 11秒

实例三：多谐振荡电路——闪烁灯/蜂鸣器

场景：让LED自动一闪一闪，不需要任何按钮，通电就工作。

接线：R1接VCC到DIS，R2接DIS到TH/TR（TH和TR连一起），TH/TR对地接C。

工作过程——充放电循环：
• 电容充电（经R1+R2）→ vC 升至 2/3 VCC → OUT翻低，DIS导通
• 电容放电（经R2到DIS）→ vC 降至 1/3 VCC → OUT翻高，DIS截止
• 又开始充电，周而复始，自动产生连续矩形脉冲波
💡 实测计算：R1=1kΩ，R2=10kΩ，C=10μF
T ≈ 0.7×(1k + 2×10k)×10μ ≈ 0.7×21k×10μ ≈ 0.15秒，频率约6.6Hz，LED快速闪烁。
若换C=100μF → T≈1.5秒，LED慢闪。
🔑 三种接法一句话总结：
• 施密特：TH和TR连一起 → 有回差的整形器
• 单稳态：TR触发一下 → 输出一个固定宽度脉冲
• 多谐振荡：RC自己充放电 → 自动连续产生方波

161 6.5 74LVC161 计数器

概述

74LVC161是4位二进制同步加计数器，具有异步清零和同步并行置数功能。

同时具有计数使能控制（CET、CEP）和并行进位输出（TC）。

🎯 作用：对输入时钟脉冲进行计数。也可用于分频、定时、产生节拍脉冲等。
🔧 能完成的功能：
① 任意进制计数——通过反馈清零法或反馈置数法，用一片161实现2~15进制计数；多片级联可扩展至更高进制
② 分频器——将输入时钟频率降低为1/N（N为计数进制）
③ 定时器——对已知频率的时钟计数，达到预设值后产生输出信号
④ 序列信号发生器——配合组合电路，产生特定序列的脉冲信号
⑤ 级联扩展——多片161通过并行进位或串行进位方式，构建8位、16位或更高位计数器

芯片特点

  • 异步清零：清零端（CLR）为低电平时，无论其他输入如何，立即清零。
  • 同步并行置数：预置端（LOAD）为低电平时，在时钟CP上升沿将D3~D0数据装入。
  • 计数使能：CET和CEP同时为高电平时，在时钟CP上升沿进行加1计数。
  • 并行进位输出：TC = CET · Q3Q2Q1Q0

用161构成任意进制计数器

（1）反馈清零法：利用异步清零输入端，在M进制计数器的计数过程中，跳过M‒N个状态，得到N进制计数器。

（2）反馈置数法：利用同步置数端，在M进制计数器的计数过程中，跳过M‒N个状态，得到N进制计数器。

多片级联扩展

当需要N > M（M=16）时，需用多片161级联。通常有两种方式：

  • 并行进位：低位片的进位信号作为高位片的使能信号（同步方式）。
  • 串行进位：低位片的进位信号作为高位片的时钟脉冲（异步方式）。

138 4.4 74HC138 译码器

概述

74HC138是3线-8线二进制译码器。

译码是编码的逆过程，它能将二进制码翻译成代表某一特定含义的信号（即电路的某种状态）。

译码器：具有译码功能的逻辑电路称为译码器。

🎯 作用：将二进制码翻译成代表某一特定含义的信号（即电路的某种状态）。
🔧 能完成的功能：
① 地址译码——识别不同设备，当系统地址总线的高位地址连到译码器输入端，每个输出对应一个设备的片选信号
② 数据分配器——将公共数据线上的数据按需要分时送到不同的通道上去
③ 实现组合逻辑函数——利用译码器输出的最小项，配合门电路实现任意组合逻辑函数
④ 级联扩展——2片138构成4线-16线译码器；配合139可构成5线-32线译码器

74HC138的特点

  • 3个输入端 A2A1A0（高电平有效）
  • 8个输出端 Y0~Y7（低电平有效）
  • 3个使能端：E1、E2、E3（其中E1、E2低有效，E3高有效）
逻辑符号说明：符号框外部的符号表示外部输入或输出信号名称，字母上面的"—"号说明该输入或输出是低电平有效。符号框内部的输入、输出变量表示其内部的逻辑关系。

译码器的扩展

  • 用2片74X138可以构成4线-16线译码器。
  • 用74X139和74X138可以构成5线-32线译码器。

译码器的应用

（1）地址译码：译码器常用于识别不同设备。当系统地址总线的高位地址连到译码器输入端，每个输出对应一个设备的片选信号。

（2）数据分配器：用译码器可以实现数据分配功能，将公共数据线上的数据按需要送到不同的通道上去。
