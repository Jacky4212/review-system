第3章 二极管及其基本电路

第4章 →

📌 教学基本要求

  • 理解半导体的基本知识：本征半导体、杂质半导体（N型/P型）
  • 掌握PN结的形成原理与单向导电性
  • 理解PN结的反向击穿机制（雪崩击穿/齐纳击穿）与电容效应
  • 掌握二极管的I-V特性、主要参数和简化模型（理想/恒压降/折线/小信号）
  • 能运用模型分析法分析整流、限幅、钳位、开关等二极管应用电路
  • 了解特殊二极管：齐纳、变容、肖特基、光电器件

3.1 半导体的基本知识

3.1.1 本征半导体

1. 半导体材料

根据物体导电能力（电阻率）的不同，来划分导体、绝缘体和半导体。典型的半导体有硅（Si）和锗（Ge）以及砷化镓（GaAs）等。

本征半导体是一种完全纯净、结构完整的半导体晶体。

2. 半导体的晶体结构

硅原子通过共价键形成晶体结构。在室温（300K）下，当被束缚的价电子获得足够的随机热振动能量而挣脱共价键束缚成为自由电子时（本征激发），半导体便具备了一定的导电能力。

3. 本征半导体的导电性

空穴就是价电子挣脱束缚成为自由电子后，共价键中留下的空位。因为空穴表示共价键中失去了一个带负电荷的电子，所以认为其带有与电子电荷等量的正电荷。空穴的出现是半导体区别于导体的一个重要特点。

空穴的移动实际上反映了受束缚的价电子的移动，只是移动方向与价电子移动方向相反。可以用空穴移动产生的电流来代表价电子移动产生的电流。

载流子——可以自由移动的带电粒子。本征激发产生的自由电子和空穴总是成对出现的。自由电子和空穴都是载流子。自由电子与空穴相遇时，两者同时消失，称为自由电子与空穴的复合。外部环境不变的情况下，载流子的产生与复合达到动态平衡。

温度特性：当温度升高时，将产生更多的自由电子和空穴，意味着载流子的浓度升高，晶体的导电能力也会增强。即本征半导体的电导率将随温度的升高而增加。

3.1.2 杂质半导体

在本征半导体中掺入某些微量元素作为杂质，可使半导体的导电性发生显著变化。掺入的杂质主要是三价或五价元素。掺入杂质的本征半导体称为杂质半导体。

P型半导体

掺入三价杂质元素（如硼）的半导体。因三价杂质原子在与硅原子形成共价键时，缺少一个价电子而在共价键中留下一个空穴。在P型半导体中空穴是多数载流子（多子），它主要由掺杂形成；自由电子是少数载流子（少子），由热激发形成。三价杂质因而也称为受主杂质。

N型半导体

掺入五价杂质元素（如磷）的半导体。因五价杂质原子中只有四个价电子能与周围四个半导体原子中的价电子形成共价键，而多余的一个价电子因无共价键束缚而很容易形成自由电子。在N型半导体中自由电子是多数载流子，它主要由杂质原子提供；空穴是少数载流子，由热激发形成。五价杂质原子也称为施主杂质。

掺杂效果：掺入杂质对本征半导体的导电性有很大的影响。典型数据：本征硅的原子浓度约 1022/cm³，掺杂浓度约 1016/cm³（仅百万分之一），载流子浓度即可增加约 106 倍。以上三个浓度基本上依次相差 106/cm³。

3.2 PN结的形成及特性

3.2.1 PN结的形成

1. 载流子的漂移与扩散

  • 漂移运动：在电场作用下引起的载流子运动
  • 扩散运动：由载流子浓度差引起的载流子运动

2. PN结的形成过程

在一块本征半导体两侧通过扩散不同的杂质，分别形成N型半导体和P型半导体。此时将在N型和P型半导体的结合面上形成如下物理过程：

形成步骤：
① 因浓度差 → 多子的扩散运动（P区空穴向N区扩散，N区电子向P区扩散）
② → 由杂质离子形成空间电荷区（耗尽层、势垒区）
③ → 空间电荷区形成内电场（由N区指向P区）
④ → 内电场促使少子漂移 / 内电场阻止多子扩散
⑤ 最后，多子的扩散和少子的漂移达到动态平衡

3.2.2 PN结的单向导电性

当外加电压使PN结中P区的电位高于N区的电位，称为加正向电压，简称正偏；反之称为加反向电压，简称反偏。

外加正向电压（正偏）外加反向电压（反偏）
对内电场影响削弱内电场增强内电场
PN结电阻减小（低电阻）增大（高电阻）
载流子运动有利于多子扩散阻止多子扩散，有利于少子漂移
电流特性大的正向扩散电流很小的反向漂移电流（反向饱和电流 IS）
结论：PN结具有单向导电性。正向偏置时呈现低电阻，具有较大的正向扩散电流；反向偏置时呈现高电阻，具有很小的反向漂移电流。

PN结的I−V特性方程

iD = IS (evD/VT − 1)

其中 IS ——反向饱和电流，VT ——温度电压当量，在常温下（T = 300K）VT = kT/q ≈ 26 mV。

3.2.3 PN结的反向击穿

当PN结的反向电压增加到一定数值时，反向电流突然快速增加，此现象称为PN结的反向击穿。分为：

  • 热击穿——不可逆（损坏器件）
  • 电击穿——可逆（在限流条件下）

雪崩击穿

反向电压增大 → 电场足够强 → 漂移运动的少子获得足够的动能 → 撞击出更多的自由电子-空穴对 → 新的自由电子-空穴对继续撞击出更多 → 载流子的倍增效应 → 雪崩击穿。

齐纳击穿

反向电压增大 → 电场足够强 → 直接破坏共价键的束缚，分离出电子，产生大量的自由电子-空穴对 → 形成较大的反向电流 → 齐纳击穿。

3.2.4 PN结的电容效应

  • 扩散电容 CD：由PN结正向偏置时非平衡少子的存储效应引起，与正向电流成正比
  • 势垒电容 CB：由空间电荷区宽度随外加电压变化引起，类似于平行板电容

PN结的电容效应限制了二极管在高频下的应用。反向偏置时势垒电容占主导，正向偏置时扩散电容占主导。

3.3 二极管

结构类型

  • 点接触型二极管：PN结面积小，结电容小，用于检波和变频等高频电路
  • 面接触型二极管：PN结面积大，用于工频大电流整流电路

二极管的I−V特性

特性区域硅二极管 (2CP10)锗二极管 (2AP15)
门坎电压 Vth约 0.5~0.7 V约 0.1~0.3 V
正向导通压降约 0.7 V约 0.3 V
反向饱和电流很小（nA级）较大（μA级）

I−V特性三个区域：①正向特性 ②反向特性 ③反向击穿特性。Vth——门坎电压（死区电压），VBR——反向击穿电压。

主要参数

  • 最大整流电流 IF：二极管长期运行时允许通过的最大正向平均电流
  • 最大反向工作电压 VR：允许施加的最大反向电压（通常为 VBR 的一半）
  • 反向饱和电流 IS：未击穿时的反向电流，越小越好
  • 最高工作频率 fM：受结电容限制的最高工作频率

3.4 二极管基本电路及其分析方法

3.4.1 简单二极管电路的图解分析法

利用二极管的I−V特性曲线和负载线求解静态工作点Q（VD, ID）。负载线方程为：

iD = (VDD − vD) / R

是一条斜率为 −1/R 的直线，称为负载线。Q的坐标值（VD, ID）即为所求，Q点称为电路的工作点。

3.4.2 二极管电路的简化模型分析法

1. 二极管模型

模型正向偏置反向偏置适用场景
理想模型vD = 0（短路）iD = 0（开路）大信号、电源电压远大于 VD
恒压降模型vD = 0.7V (Si) / 0.3V (Ge)iD = 0一般分析，最常用
折线模型vD = Vth + iD·rDiD = 0要求更精确时
小信号模型rd = VT / IDQ（Q点处切线斜率的倒数，即微变电阻）小信号交流分析
小信号模型特别注意：
  • 小信号模型中的微变电阻 rd 与静态工作点Q有关
  • 该模型用于二极管处于正向偏置条件下，且 vD ≫ VT (= 26mV)
  • Q点切线的斜率（电导）：gd = 1/rd = IDQ / VT
符号中大小写的含义：
大写字母大写下标：静态值（直流），如 IB
小写字母大写下标：总量（直流+交流），如 iB
小写字母小写下标：瞬时值（交流），如 ib

2. 模型分析法应用举例

（1）整流电路

半波整流：二极管采用理想模型时，负载上的平均电压 VL ≈ 0.45Vs（Vs 为变压器次级电压有效值）。二极管承受的最大反向电压 VRM = √2 Vs。

桥式整流：二极管采用理想模型时，负载上的平均电压 VL ≈ 0.9Vs。二极管承受的最大反向电压 VRM = √2 Vs。

（2）限幅电路

利用二极管的单向导电性将输出电压限制在某一范围内。分析时可用理想模型或恒压降模型。

（3）钳位电路

利用二极管和电容将信号的整体电平搬移到某一参考电平。二极管用理想模型，电路处于稳态时电容上的电压维持不变。

（4）开关电路

利用二极管的导通/截止状态实现逻辑判断。分析方法：先断开二极管，比较阳极电位和阴极电位——阳极电位高于阴极电位则导通，否则截止。导通后，二极管压降等于零（理想模型），即输出电位近似等于阳极电位。

（5）小信号工作情况分析

分析方法分为两步：

  1. 直流分析：令交流信号源为零（vs = 0），求静态工作点 Q（IDQ, VDQ）
  2. 交流分析：令直流电源为零（VDD = 0），用微变电阻 rd = VT/IDQ 替换二极管，建立小信号等效电路求解

总响应 = 直流分量 + 交流分量：vO = VO + vo

3.5 特殊二极管

3.5.1 齐纳二极管（稳压二极管）

利用二极管反向击穿特性实现稳压。齐纳二极管稳压时工作在反向电击穿状态。正常稳压时 VO = VZ。

稳压条件：反向电流需在 IZmin ~ IZmax 范围内。限流电阻 R 的选择需保证在最坏情况下（VI 最大且 RL 最大时，IZ < IZmax；VI 最小且 RL 最小时，IZ > IZmin）。

3.5.2 变容二极管

结电容随反向电压显著变化的二极管，用于压控振荡器（VCO）和调谐电路。反向偏压越大，结电容越小。

3.5.3 肖特基二极管（SBD）

由金属-半导体接触形成，而非PN结。特点：正向压降小（约 0.3~0.4V）、开关速度极快、无少子存储效应。用于高频整流和高速开关电路。

3.5.4 光电器件

  • 光电二极管：将光转换为电的二极管，工作在反向偏置状态下，其反向电流随光照强度变化
  • 发光二极管（LED）：将电转换为光的二极管，通过一定正向电流时会发光
  • 激光二极管（LD）：产生相干光的半导体器件
  • 太阳能电池：将光能直接转换为电能的器件，工作在第三象限（不需要外加偏压即可产生功率输出）
