一、运算放大器电路（ch02）

PPT来源：ch02 2.2~2.4

1. 核心法则

虚短：vP ≈ vN | 虚断：iP ≈ 0, iN ≈ 0

PPT原文：""虚短"和"虚断"是用来分析各种运放线性应用电路的有力法则，必须熟练掌握。"（ch02 2.2）

2. 同相放大 vs 反相放大

同相放大反相放大
电路特征信号从同相端(+)输入信号从反相端(−)输入
电压增益Av = 1 + R2/R1Av = −Rf/R1
输入电阻Ri → ∞（极高）Ri = R1
输出电阻Ro → 0Ro → 0
共模电压有（vP = vi）无（虚地，vN ≈ 0）
相位关系同相反相
特例R2=0→电压跟随器 Av=1Rf=R1→反相器 Av=−1

3. 电压跟随器

同相放大的特例（R2=0或R1=∞）：Av = 1。作用——"隔离或缓冲"。PPT原文："电压跟随器对电压增益有贡献吗？隔离或缓冲"

4. 信号运算电路

电路类型输出-输入关系要点
反相加法vo = −Rf(vi1/R1 + vi2/R2 + …)虚短虚断+N点KCL
求差电路vo = (R4/R1)(vi2−vi1)需 R3/R2=R4/R1
积分电路vo = −(1/RC)∫vi dt负号表示反相
微分电路vo = −RC·dvi/dt方波入→尖脉冲出
仪用放大器高输入阻抗差分放大如INA128，用于心电信号

5. 分析注意事项

  • 运放正常工作时必须提供工作电源
  • 实际运放带宽有限——"需要特别注意，它们最大的差别是，理想运放的频带宽度是无限的，而实际运放的带宽是有限的。"
  • 用理想运放分析误差约0.05%，完全可行

二、共源(CS)/共射(CE)放大电路（ch04/ch05）

PPT来源：ch04 4.2~4.4（共源），ch05 5.2（共射）

1. 静态工作点（Q点）分析

步骤MOSFET共源（ch04 4.2.2）BJT共射（ch05 5.2.1）
直流偏置VGSQ=VGG(或分压)一般硅管VBEQ=0.7V
漏/集电流IDQ=Kn(VGSQ−VTN)²ICQ=β·IBQ
漏/集电压VDSQ=VDD−IDQ·RdVCEQ=VCC−ICQ·Rc
关键验证"必须检验是否满足恒流区工作条件"（FET）或放大区条件（BJT）。如不满足"必须作出新的假设，同时重新分析电路。"

2. 小信号模型与动态分析

MOSFET共源BJT共射
受控源类型VCCS：gm·vgsCCCS：β·ib
跨导/输入电阻gm=2Kn(VGSQ−VTN)rbe=200+(1+β)·26mV/IEQ
电压增益Av=−gm(Rd‖RL)Av=−β(Rc‖RL)/rbe
输入电阻Ri=Rg1‖Rg2Ri=Rb‖rbe
输出电阻Ro=Rd‖rdsRo=Rc
小信号前提vgs≪2(VGSQ−VTN)小信号，H参数简化

3. 三种组态对比

组态AvRiRo相位用途
共源(CS)/共射(CE)高(−)中/高中反相电压放大
共漏(CD)/共集(CC)≈1高低同相缓冲/阻抗变换
共栅(CG)/共基(CB)中(+)低中同相高频/宽带

三、RC桥式（文氏桥）正弦波振荡电路（ch10）

PPT来源：ch10 10.5~10.6

1. 电路组成

由RC串并联选频网络（正反馈通路）+ 同相放大电路（提供增益）+ 稳幅环节组成。PPT原文："RC正弦波振荡电路一般用于产生频率低于1MHz的正弦波。"

2. 选频特性（RC串并联网络）

fo = 1/(2πRC) | |F|max = 1/3（在f=fo时） | φF = 0°（在f=fo时）

3. 振荡条件

起振稳幅
幅值条件|AF| > 1 → Av > 3|AF| = 1 → Av = 3
相位条件φA + φF = 0°（或2nπ）

4. 起振信源与稳幅

起振信源：PPT原文："起振的信号源来自何处？电路器件内部噪声以及电源接通扰动。噪声中，满足相位平衡条件的某一角频率ω0的噪声信号被放大，成为振荡电路的输出信号。"

稳幅措施：①负温度系数(NTC)热敏电阻；②JFET压控电阻（"T为压控电阻"）；③二极管限幅。

PPT原文："当输出信号幅值增加到一定程度时，就要限制它继续增加，否则波形将出现失真。"

四、负反馈放大电路（ch08）

PPT来源：ch08 8.1~8.6

1. 反馈基本概念

PPT原文："将放大电路输出量（电压或电流）的一部分或全部，通过某种电路（称为反馈网络）送回到输入回路的过程。"

开环增益 A = xO/xID | 反馈系数 F = xF/xO | 闭环增益 Af = xO/xI

2. 反馈分类与判断

分类维度类型判断方法
极性正反馈 / 负反馈瞬时极性法——从输入开始，沿信号方向逐级标注，看反馈信号是增大还是减小净输入
输入端连接串联 / 并联反馈信号与输入在同一端→并联；不同端→串联
输出端取样电压 / 电流负载短路后反馈消失→电压反馈；仍存在→电流反馈
交直流直流 / 交流直流反馈稳Q点；交流反馈改善动态性能

3. 四种负反馈组态

组态稳定量Ri变化Ro变化典型电路
电压串联vo增大减小射极跟随器
电压并联vo减小减小反相放大
电流串联io增大增大射极带Re
电流并联io减小增大—

4. 闭环增益与深度负反馈

Af = A/(1+AF) | 深度负反馈(AF≫1)：Af ≈ 1/F

PPT原文："即闭环增益只取决于反馈网络。当反馈网络由稳定的线性元件组成时，闭环增益将有很高的稳定性。"（ch08 8.3.1）

⚠ PPT原文警告："即环路增益直接影响着误差的大小，环路增益越大，误差越小。注：此处忽略了频率变化导致A减小带来的影响。"（ch08 8.4）

5. 负反馈对性能的影响

  • 提高增益稳定性——闭环增益只取决于反馈网络
  • 扩展通频带——增益带宽积为常数
  • 减小非线性失真——反馈将失真分量送回输入端预矫正
  • 抑制反馈环内噪声
  • 改变输入/输出电阻——见上表

五、比较器电路（ch10）

PPT来源：ch10 10.8 非正弦信号产生电路

1. 单门限比较器

原理：运放开环（或正反馈）工作，比较输入电压vi与参考电压VREF。vi>VTH→输出一种饱和状态；vi

输出电压：受稳压管限幅，Uo=±VZ。

缺点：PPT原文——"单门限比较器的抗干扰能力"差，vi在门限附近因噪声导致输出反复跳变（震颤）。

2. 施密特触发器（迟滞比较器）

改进：引入正反馈→门限电压随输出电压变化→具有迟滞特性。

单门限比较器施密特触发器
门限电压固定（VTH=VREF）上下门限不同（VTH+ ≠ VTH−）
抗干扰差，易震颤好，滞回宽度抑制噪声
传输特性单次跃变滞回曲线（有记忆）

3. 集成比较器

PPT原文："开环增益低、失调电压大、共模抑制比小，灵敏度往往不如用集成运放构成的比较器高。"

六、OCL / OTL 功率放大电路（ch09）

PPT来源：ch09 9.1~9.4

1. 功放分类

类别导通角效率特点
甲类(A)360°≤25%静态电流大，效率最低
乙类(B)180°≤78.5%静态电流≈0，有交越失真
甲乙类(AB)>180°介于甲/乙间小静态偏流克服交越失真
丁类(D)开关态>90%PWM+低通滤波

PPT原文："提高效率的主要途径：降低静态功耗，即减小静态电流。"（ch09 9.1）

2. OCL vs OTL

OCL（双电源）OTL（单电源）
电源±VCC+VCC + 输出电容
输出端静态电压0VVCC/2
最大输出功率Pomax = VCC²/(2RL)Pomax = VCC²/(8RL)
最大效率π/4 ≈ 78.5%π/4 ≈ 78.5%
结构NPN+PNP互补对称推挽同上+输出大电容

3. 交越失真及克服

原因：乙类Q点在截止点，"乙类互补对称电路存在的问题"——输入过零时|vBE|<死区电压(0.7V)，两管均不导通。

克服：改为甲乙类。PPT原文："利用二极管进行偏置克服交越失真。利用VBE扩大电路进行偏置克服交越失真。"

  • 二极管偏置：两管基极间串两个二极管≈1.4V偏压
  • VBE倍增电路：一BJT+两电阻，等效可调电压源

4. OCL输出级关键认识

OCL输出级是共集电极（射极跟随器）结构→电压增益Av≈1。没有电压放大功能！电压放大由前级运放完成，功放只做功率输出。
