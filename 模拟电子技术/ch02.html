  • 了解集成电路运算放大器的内部结构、电路符号和封装
  • 掌握运算放大器传输特性（线性区和饱和区）
  • 熟练掌握理想运放的两条重要法则：虚短和虚断
  • 掌握同相放大电路和反相放大电路的分析与设计
  • 掌握电压跟随器的作用（隔离/缓冲）
  • 掌握求和电路、求差电路、仪用放大器的原理
  • 掌握积分和微分电路的工作原理

2.1 集成电路运算放大器

1. 集成电路运算放大器简介

集成电路运算放大器（简称运放）是一种高增益的直接耦合放大器，内部结构包含输入级、中间级、输出级和偏置电路。常见封装形式有双列直插式（DIP）等。

电路符号与端口

  • 反相输入端（vN，标记"−"）：输出信号与该输入端信号相位相反
  • 同相输入端（vP，标记"+"）：输出信号与该输入端信号相位相同
  • 输出端（vO）

运算放大器无特定接地端，但正常工作时必须提供工作电源。通常正负电源的连接方式为：正电源 V+ 和负电源 V−。

2. 运算放大器的电路模型

运放的电路模型包括：

  • 输入电阻 ri：很大，从输入端看进去的等效电阻
  • 输出电阻 ro：很小，输出端的戴维南等效电阻
  • 电压控制电压源 Avo(vP − vN)：表示运放的电压放大能力

3. 运算放大器的传输特性

运放的传输特性 vO = f(vP − vN) 分为两个区域：

参数典型值
开环电压增益 Avo≥ 105（很高）
输入电阻 ri≥ 106 Ω（很大）
输出电阻 ro≤ 100 Ω（很小）

线性范围：vO = Avo(vP − vN)，（V− ＜ vO ＜ V+）

注意输入输出的相位关系：同相端输入时输出与输入同相，反相端输入时输出与输入反相。

饱和区：

  • 当 (vP − vN) > 0，且 Avo(vP − vN) ≥ V+ 时，vO = +Vom ≈ V+
  • 当 (vP − vN) < 0，且 Avo(vP − vN) ≤ V− 时，vO = −Vom ≈ V−

4. 差模信号和共模信号

差模信号：两个输入端信号的差值，vid = vP − vN

共模信号：两个输入端信号的平均值，vic = (vP + vN) / 2

任意两个输入信号都可以分解为差模分量和共模分量：

vP = vic + vid/2， vN = vic − vid/2

2.2 理想运算放大器

1. 理想运算放大器的参数

  • (1) 开环电压增益 Avo → ∞
  • (2) 输入电阻 ri = ∞
  • (3) 输出电阻 ro = 0
  • (4) 开环带宽 BW → ∞
  • (5) 当 vP = vN 时，vO = 0（零输入时零输出）

2. 虚短和虚断

虚短（vP ≈ vN）：
若 V− < vO < V+，有 vO = Avo(vP − vN)
则 (vP − vN) = vO / Avo → 0，即 vP ≈ vN
两个输入端之间近似短路，但不是真正的短路，故称"虚短"。
虚断（iP ≈ 0, iN ≈ 0）：
输入电阻 ri 的阻值很高，使 iP = −iN = (vP − vN)/ri ≈ 0
两个输入端流入的电流近似为零，但不是真正的断路，故称"虚断"。
特别注意：vP ≈ vN，iP ≈ 0、iN ≈ 0 —— "虚短"和"虚断"是用来分析各种运放线性应用电路的有力法则，必须熟练掌握。
为什么不能用开环运放直接对信号进行线性放大？因为开环增益极高，输入信号非常小才能工作在线性区，且此时运放的带宽也很窄。实际上很难稳定工作。

2.3 基本线性运放电路

实际应用中，线性放大时都需要引入负反馈，使运放工作在线性区。负反馈：将输出量（电压或电流）送回到输入端，反馈信号减小原来加到放大器输入端的信号。

由于实际运放与理想运放特性很接近，在工程应用时，都将实际运放当作理想运放来简化分析和设计。需要特别注意，它们最大的差别是：理想运放的频带宽度是无限的，而实际运放的带宽是有限的。

2.3.1 同相放大电路

（1）电压增益 Av

根据理想运放特性：vP ≈ vN（虚短），iP = −iN = 0（虚断）

Av = vo / vi = 1 + R2 / R1

（可作为公式直接使用）输出与输入同相，故称同相放大电路。

误差分析

设 Avo = 105, ri = 106Ω, ro = 100Ω, R1 = 1kΩ, R2 = 49kΩ：

  • 采用实际运放模型的电压增益 Av ≈ 49.975
  • 采用理想运放模型的电压增益 Av = 50
  • 产生的相对误差约为 0.05%

实际上，电阻 R1 和 R2 如果用 E48 系列的阻值，则会有 ±2% 的误差，所以用理想运放代替实际运放进行电路分析和设计完全可行。

（2）输入电阻 Ri

根据虚短和虚断：vi = vP，ii = iP ≈ 0，所以 Ri → ∞。

（3）输出电阻 Ro

Ro → 0。

输入电阻趋于无穷大；输出电阻趋于 0，因此带负载能力强，所带负载电阻大小不影响其运算关系。

电压跟随器

同相放大电路的一种特殊形式（R2 = 0 或 R1 = ∞）：

vo = vn ≈ vP = vi， Av = 1

电压跟随器的作用是隔离或缓冲。没有电压跟随器时，负载直接从信号源取电流，负载上得到的电压受信号源内阻影响；有电压跟随器后，iP ≈ 0，vP = vs，根据虚短和虚断 vo = vn ≈ vP = vs，负载与信号源隔离。

2.3.2 反相放大电路

（1）电压增益 Av

根据虚短和虚断：vn ≈ vP = 0（虚地），in = 0，所以 i1 = if：

Av = vo / vi = −Rf / R1

（可作为公式直接使用）输出与输入反相，故称反相放大电路。若 R1 = Rf 时，Av = −1，习惯称为反相器。

（2）输入电阻 Ri

Ri = vi / i1 = R1

（3）输出电阻 Ro

Ro → 0。

两种放大电路比较：若信号源是非理想的电压信号源（有内阻），采用同相放大电路更好，因为同相放大电路输入电阻无穷大，不受信号源内阻影响；反相放大电路的输入电阻为 R1，受限于反馈电阻网络。
特性同相放大电路反相放大电路
电压增益Av = 1 + R2/R1（正）Av = −Rf/R1（负）
输入电阻Ri → ∞Ri = R1
输出电阻Ro → 0Ro → 0
虚短/虚地vP ≈ vN = vivP = vN = 0（虚地）
共模输入电压有共模电压 = vi无共模电压（虚地）

2.4 同相输入和反相输入放大电路的其他应用

2.4.1 求和电路

反相加法

根据虚短、虚断和 N 点的 KCL 方程：

vo = −Rf (vi1/R1 + vi2/R2 + … + vin/Rn)

当 R1 = R2 = … = Rn = Rf 时，vo = −(vi1 + vi2 + … + vin)。

2.4.2 求差电路

利用叠加原理：

vo = (1 + R4/R1) · [R3/(R2+R3)] · vi2 − (R4/R1) · vi1

当 R3/R2 = R4/R1 时：

vo = (R4/R1)(vi2 − vi1)

电压增益：Avd = R4/R1（或 R3/R2）。

差模输入电阻：Rid = R1 + R2。

2.4.3 仪用放大器

仪用放大器（Instrumentation Amplifier）是一种高输入阻抗、高共模抑制比的差分放大器，广泛应用于传感器信号调理。

基本结构：两个同相放大器作为输入级（提供高输入阻抗），后接求差电路作为输出级。

集成仪用放大器如 INA128，广泛应用于心电信号（ECG）等微弱信号的放大。

应用实例——心电信号放大电路中，通过右腿驱动电路将共模电压反馈到人体，大大减小了 INA128 输入端的共模电压，其中 K = R6/R5。

2.4.4 积分和微分电路

1. 积分电路

将反相放大电路中的反馈电阻 Rf 用电容 C 替换：

vo = −(1/RC) ∫0t vi(t) dt

（设电容器 C 的初始电压为零）。负号表示 vO 与 vI 在相位上是相反的。

积分电路的应用：当输入为阶跃电压时，输出为线性斜坡电压。与一般 RC 电路相比，运放积分电路利用虚地使得电容充电电流恒定（= vi/R），输出电压线性度更好。

2. 微分电路

将反相放大电路中的输入电阻 R1 用电容 C 替换：

vo = −RC · dvi/dt

微分电路的应用：当输入为方波信号时，输出为尖脉冲——在方波的上升沿和下降沿处，dvi/dt 很大，产生尖脉冲输出。
