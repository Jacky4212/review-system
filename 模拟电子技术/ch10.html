第10章 信号处理与信号产生电路

返回首页 →

📌 教学基本要求

  • 掌握滤波电路的分类（LPF/HPF/BPF/BRF/APF）和基本概念
  • 掌握一阶和二阶有源滤波电路的结构与传递函数
  • 理解正弦波振荡电路的自激振荡条件（幅值平衡和相位平衡）
  • 掌握RC桥式（文氏桥）正弦波振荡电路的工作原理
  • 了解非正弦信号产生电路（比较器/方波/三角波发生器）

10.1 滤波电路的基本概念与分类

1. 基本概念

滤波器：是一种能使有用频率信号通过而同时抑制或衰减无用频率信号的电子装置。
有源滤波器：由有源器件（如运放）和相关元件构成的滤波器。

滤波电路的传递函数（s域）：

T(s) = Vo(s) / Vi(s)

|T(jω)| —— 幅频响应（模）；φ(ω) —— 相频响应（相位角）。群时延响应 τ(ω) = −dφ(ω)/dω，相位失真与群时延响应有关。

2. 分类

类型通带应用举例
低通（LPF）0 ~ fH滤除高频噪声
高通（HPF）fL ~ ∞阻断直流分量
带通（BPF）fL ~ fH选频放大（如收音机中频）
带阻（BRF）0 ~ fL 及 fH ~ ∞抑制50Hz工频干扰（陷波器）
全通（APF）全部频率相位校正/时延均衡
希望抑制50Hz的干扰信号，应选用哪种类型的滤波电路？（带阻/陷波器）放大音频信号应选用？（带通滤波器）

3. 频率响应的逼近方式

  • 巴特沃斯（Butterworth）：通带内最平坦，无纹波
  • 切比雪夫（Chebyshev）：通带内有等幅纹波，过渡带更陡
  • 反切比雪夫：阻带内有等幅纹波
  • 椭圆函数（Cauer）：通带和阻带均有纹波，过渡带最陡

4. 实际滤波电路的参数

  • 通带纹波 γmax、通带截止角频率 ωp
  • 阻带截止角频率 ωs、阻带最小衰减量 γmin
  • 频率选择性因子 = ωs/ωp

10.2 一阶有源滤波电路

1. 低通（LPF）

传递函数（同相放大结构）：

T(s) = A0 / (1 + s/ωc)，其中 ωc = 1/RC 为特征角频率

一阶滤波器的带外衰减速率较慢（−20dB/dec）。

2. 高通（HPF）

将低通电路中的电容和电阻对换，便成为高通电路。传递函数：

T(s) = A0 · s/ωc / (1 + s/ωc)

有源滤波器与无源滤波器相比：优点是不用电感、体积小、重量轻，有一定的电压放大和缓冲作用；缺点是工作频率难以做得很高，不适宜大功率场合。

10.3 高阶有源滤波电路

10.3.1 有源低通滤波电路

1. 二阶压控电压源型（Sallen-Key）

传递函数：

T(s) = A0 / [1 + (3−A0)sRC + (sRC)²]

令通带增益 A0 = 1 + Rf/R1，特征角频率 ωc = 1/RC，等效品质因数 Q = 1/(3−A0)。

Q值与滤波特性：
  • Q = 0.707（巴特沃斯）：通带内最平坦，无过冲
  • Q > 0.707（切比雪夫）：通带内有过冲（纹波），过渡带更陡
  • Q < 0.707：无过冲，但截止特性较差

2. 二阶无限增益多路反馈型

传递函数分母不变，Q值不会出现负值，对增益无限制。通过级联二阶或一阶有源滤波电路构成高阶有源滤波电路。n阶巴特沃斯归一化幅频响应：|T(jω)| = A0 / √(1+(ω/ωc)²ⁿ)。

10.3.2 有源高通滤波电路

将低通电路中的电容和电阻位置互换即可得到高通电路。

10.3.3 有源带通滤波电路

可由低通和高通串联得到，需满足低通截止频率 > 高通截止频率。

10.3.4 有源带阻滤波电路

可由低通和高通并联得到，或采用双T选频网络构成陷波器。

10.5 正弦波振荡电路的振荡条件

1. 振荡条件

正反馈放大电路的闭环增益：Af = A/(1−AF)。当 AF = 1 时，Af → ∞，产生自激振荡。

幅值平衡条件：|AF| = 1
相位平衡条件：φA + φF = 2nπ（n为整数）

2. 起振和稳幅

起振条件：|AF| > 1。起振的信号源来自电路器件内部噪声以及电源接通扰动。噪声中，满足相位平衡条件的某一角频率 ω0 的噪声信号被放大，成为振荡电路的输出信号。

当输出信号幅值增加到一定程度时，就要限制它继续增加，否则波形将出现失真——这就是稳幅环节的作用。

3. 振荡电路基本组成部分

  1. 放大电路（包括负反馈放大电路）
  2. 反馈网络（构成正反馈）
  3. 选频网络（选择满足相位平衡条件的一个频率，经常与反馈网络合二为一）
  4. 稳幅环节

10.6 RC正弦波振荡电路

1. RC桥式振荡电路（文氏桥振荡器）

由RC串并联选频网络作为正反馈通路，配合负反馈放大电路构成。

2. RC串并联选频网络的选频特性

反馈系数（令 ω0 = 1/RC）：

F = Vf/Vo = 1 / [3 + j(ω/ω0 − ω0/ω)]

当 ω = ω0 = 1/RC 时：|F|max = 1/3，相移 φF = 0°。

3. 振荡电路工作原理

满足相位平衡条件（φA + φF = 0°），若放大电路的电压增益 A > 3，则满足振幅平衡条件 |AF| > 1。

RC正弦波振荡电路一般用于产生频率低于 1 MHz 的正弦波。

4. 稳幅措施

  • 热敏电阻稳幅：利用热敏电阻的阻值随温度变化自动调节增益
  • 场效应管（JFET）稳幅：T为压控电阻，通过整流滤波电路控制栅极电压，自动调节增益
  • 二极管稳幅：利用二极管的非线性特性实现自动增益控制

RC移相式正弦波振荡电路

利用多级RC移相网络实现180°相移，配合反相放大电路实现振荡。通常用于固定频率的低频振荡。

10.8 非正弦信号产生电路

非正弦信号产生电路通常利用比较器和RC充放电回路实现：

  • 方波发生器：由施密特触发器（正反馈比较器）和RC积分电路构成
  • 三角波发生器：由方波发生器后接积分器构成
  • 锯齿波发生器：改变积分器的充放电时间常数比例

555定时器是多功能非正弦信号产生电路的典型集成器件，可构成多谐振荡器、单稳态触发器和施密特触发器。
