第9章 功率放大电路

第10章 →

📌 教学基本要求

  • 了解功率放大电路与电压放大电路的区别
  • 掌握甲/乙/甲乙/丙/丁类功放的工作状态分类
  • 掌握乙类双电源互补对称功放（OCL）的分析计算
  • 理解交越失真的产生原因及消除方法（甲乙类）
  • 了解丁类（D类）功放的工作原理
  • 了解功率管的安全工作与散热问题

9.1 功率放大电路的一般问题

1. 功率放大电路的特点及主要研究对象

放大电路实质上都是能量转换电路。从能量控制的观点来看，功率放大电路和电压放大电路没有本质的区别。但它们的任务不同：

  • 电压放大电路：得到不失真的电压输出信号，关心电压增益
  • 功率放大电路：获得一定的不失真（或失真较小）的输出功率，更关注效率而非功率增益

功率放大电路是一种以输出较大功率为目的的放大电路，因此要求同时输出较大的电压和电流，三极管工作在接近极限状态。要解决的问题：提高效率、减小失真、三极管的保护。

2. 输出级工作状态分类及提高效率的主要途径

提高效率的主要途径：降低静态功耗，即减小静态电流。

根据正弦信号整个周期内三极管的导通情况划分：

类别导通角特点效率
甲类(A)360°（一个周期内均导通）静态电流大，效率最低≤25%（电阻负载）
乙类(B)= 180°静态电流为零，存在交越失真≤78.5%（理论）
甲乙类(AB)> 180°小静态电流克服交越失真介于甲类和乙类之间
丙类(C)< 180°用于高频谐振功放最高
丁类(D)开关状态三极管工作于开关状态，效率极高> 90%

9.2 射极输出器——甲类放大的实例

射极输出器（共集电极放大电路）作为甲类功放的典型实例。其特点是：电压增益≈1，输入阻抗高，输出阻抗低。但由于静态电流的存在，效率很低。

9.3 乙类双电源互补对称功率放大电路（OCL）

1. 电路组成

由一对NPN和PNP三极管（T1和T2）组成互补对称结构。基本互补对称电路实现了静态时两管不导电，而在有信号时，T1和T2轮流导电，组成推挽式电路。双电源 ±VCC 供电，输出直接耦合到负载（无输出电容，故称OCL——Output Capacitor-Less）。

2. 分析计算（大信号下图解法）

（1）输出功率 Po

Po = Vom² / (2RL)

最大输出功率（忽略 VCES 时）：

Pomax = VCC² / (2RL)

（2）管耗 PT

设输出电压为 vo = Vom sinωt，单管在半个周期内的管耗：

PT = (1/RL) · [(VCCVom/π) − (Vom²/4)]

（3）直流电源供给的功率 PV

PV = 2VCCVom / (πRL)

（4）效率 η

η = Po / PV = (π/4) · (Vom/VCC)

当 Vom = VCC 时，最大效率：

ηmax = π/4 ≈ 78.5%
交越失真：乙类功放在输入信号的零点附近，由于三极管需要克服死区电压（|vBE| < 0.7V），两管均不导通，输出电压在零点附近出现"平台"状的失真。

9.4 甲乙类互补对称功率放大电路

为克服乙类功放的交越失真，给两个输出管提供小静态偏置电流（微导通状态），使其工作在甲乙类。

常见实现方式：

  • 二极管偏置：在两个输出管的基极之间接入两个串联二极管（或VBE倍增电路），提供约 1.4V 的偏置电压
  • VBE倍增电路：由一只三极管和两个电阻组成，等效于一个可调节的电压源，提供稳定的偏置电压

单电源互补对称功放（OTL）

当只有单电源供电时，输出端需通过大电容耦合到负载（OTL——Output Transformer-Less）。静态时，输出端电压为 VCC/2。

特性OCL（双电源）OTL（单电源）
电源±VCCVCC
输出端静态电压0VVCC/2
输出耦合直接耦合电容耦合
最大输出功率VCC²/(2RL)VCC²/(8RL)

9.5 丁类（D类）功率放大电路原理简介

D类功放的三极管工作于开关状态（导通时饱和，截止时关断），理论上管耗为零，效率可接近 100%。

工作原理：输入信号通过PWM（脉宽调制）转换为高频方波 → 开关功率管放大 → 低通滤波器滤除高频载波，恢复信号波形。D类功放广泛应用于便携式音频设备、手机等要求高效率的场合。

9.6 功率管

功率管的安全工作需要考虑：

  • 二次击穿：大电流下的局部热点导致的破坏性击穿
  • 散热设计：功率管的散热器选择，热阻 θJA（结到环境）、θJC（结到外壳）
  • 安全工作区（SOA）：由最大电流、最大电压、最大耗散功率和二次击穿限制围成的区域

常用的功率管类型：功率BJT、功率MOSFET（VMOS/VDMOS）、IGBT等。
