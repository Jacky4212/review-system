📌 教学基本要求

  • 了解信号与信号频谱的基本概念
  • 掌握模拟信号与数字信号的区别
  • 理解放大电路的四种模型（电压/电流/互阻/互导）
  • 掌握放大电路的主要性能指标：输入电阻、输出电阻、增益、频率响应
  • 理解频率失真（线性失真）与非线性失真的区别

1.1 信号

信号是信息的载体或表达形式。

在电子电路中，信号通常以电信号的形式存在，即随时间变化的电压或电流。例如微音器（麦克风）输出的某一段信号的波形，就是将声音信息转换为电信号。

电信号可以通过电路进行传输、处理和变换，这是模拟电子技术研究的基本对象。

1.2 信号的频谱

正弦信号

正弦信号是最基本的周期信号，其数学表达式为：

v(t) = Vm sin(ωt + φ)

其中 Vm 为振幅，ω 为角频率（ω = 2πf），φ 为初相位。

方波信号的傅里叶级数

方波信号满足狄里赫利条件，可以展开成傅里叶级数：

v(t) = Vs · (4/π) [ sinωt + (1/3)sin3ωt + (1/5)sin5ωt + … ]

方波信号可以看作由基波（角频率为ω）和奇次谐波（角频率为3ω、5ω……）叠加而成。信号的频谱描述了各频率分量的幅值和相位。

非周期信号

非周期信号不能用傅里叶级数表示，但可以通过傅里叶变换得到其频谱：

F(ω) = ∫-∞+∞ f(t) e-jωt dt

非周期信号的频谱是连续谱，包含了从零到无穷大的所有频率分量。

关键结论：实际电路的处理能力是有限的——任何实际放大电路的带宽都是有限的，只能对一定频率范围内的信号进行有效放大。

1.4 放大电路模型

1. 信号放大时电路的一般构成

放大电路需要供电电源，是一个双口网络（输入端口和输出端口）。

电路中的电位参考基准点，定义为零电位，用接地符号"⏚"表示。接地也是输入、输出和电源的共同端。

2. 放大电路增益形式

3. 放大电路模型

放大电路是一个双口网络。从端口特性来研究放大电路，可将其等效成具有某种端口特性的等效电路（此处均忽略了电抗元件的影响）。

  • 输入端口特性可以等效为一个输入电阻 Ri
  • 输出端口可以根据不同情况等效成不同的电路形式

（1）电压放大模型

输入回路中，信号源 vs 通过内阻 Rs 加到输入电阻 Ri 上：

vi = vs · Ri / (Rs + Ri)

由输出回路得：vo = Avo · vi · RL / (Ro + RL)

则电压增益为：

Av = vo / vs = Avo · [Ri / (Rs + Ri)] · [RL / (Ro + RL)]
重要结论：
  • 负载 RL 的大小会影响增益的大小——要想减小负载的影响，则希望 Ro ≪ RL（理想情况 Ro → 0）
  • 信号源内阻 Rs 会导致输入信号衰减——要想减小衰减，则希望 Ri ≫ Rs（理想情况 Ri → ∞）

（2）电流放大模型

电流增益：Ai = io / ii。理想电流放大器应满足：Ri → 0，Ro → ∞。

（3）互阻放大模型

互阻增益：Ar = vo / ii (Ω)。输入为电流，输出为电压。

（4）互导放大模型

互导增益：Ag = io / vi (S)。输入为电压，输出为电流。

（5）隔离放大模型

隔离放大器的电压增益 Avo = 1，输入电阻 Ri → ∞，输出电阻 Ro → 0，起到阻抗变换（缓冲）的作用。

1.5 放大电路的主要性能指标

1. 输入电阻 Ri

从放大电路输入端看进去的等效电阻：

Ri = vi / ii

输入电阻反映了放大电路对信号源的负载效应。Ri 越大，从信号源索取的电流越小。

2. 输出电阻 Ro

从放大电路输出端看进去的戴维南等效电阻。测量方法：将信号源置零（vs = 0，保留 Rs），在输出端加测试电压求电流。

注意：输入、输出电阻为交流电阻，不是直流电阻。

3. 增益

增益反映放大电路在输入信号控制下，将供电电源能量转换为输出信号能量的能力。

常用分贝(dB)表示增益，因为：

  • 人耳对声音的感知近似对数关系
  • 多级放大电路的总增益为各级增益的乘积，用dB表示时变为相加，便于计算

4. 频率响应

A. 频率响应及带宽

在输入正弦信号情况下，输出随输入信号频率连续变化的稳态响应，称为放大电路的频率响应。

电压增益可表示为频率的函数：

Av(jω) = |Av(jω)| ∠φ(ω)

其中 |Av(jω)| 称为幅频响应，φ(ω) 称为相频响应。

带宽 BW：放大电路增益下降至中频增益的 1/√2 倍（即 -3dB）时所对应的频率范围。

  • fL —— 下限截止频率（低频端）
  • fH —— 上限截止频率（高频端）
  • BW = fH − fL

直流放大电路的幅频响应中 fL = 0，带宽 BW = fH。

B. 频率失真（线性失真）

幅度失真：放大电路对信号中不同频率分量的放大倍数不同而产生的失真。例如当放大基波幅值的倍数大于放大二次谐波的倍数时，复合波形出现失真。

相位失真：放大电路对信号中不同频率分量产生的时延不同而出现的失真。如果基波分量和二次谐波分量经放大电路产生不同的时延，则复合波形出现失真。

频率失真（线性失真）：幅度失真和相位失真通常都是同时发生的，它们统称为频率失真，也称为线性失真。
特点：线性失真的输出信号中不会产生新的频率分量。

5. 非线性失真

由元器件（如晶体管）的非线性特性引起的失真。非线性失真会使输出信号中产生输入信号所没有的新的频率分量（谐波分量）。

非线性失真系数：

γ = √(Vo2² + Vo3² + … ) / Vo1

其中 Vo1 是输出电压信号基波分量的有效值，Vok（k ≥ 2）是高次谐波分量的有效值。

对比项频率失真（线性失真）非线性失真
产生原因电路中存在电抗元件（电容、电感），对不同频率响应不同元器件的非线性特性（如晶体管的非线性伏安特性）
新频率分量不产生新频率分量产生新的频率分量（谐波）
与信号幅度关系通常与信号幅度无关（小信号条件下）随信号幅度增大而增大
