第5章 双极结型三极管及其放大电路

第7章 →

📌 教学基本要求

  • 掌握BJT的结构特点（NPN/PNP）、工作原理和放大条件
  • 掌握BJT的I-V特性曲线（输入/输出特性）及三个工作区
  • 掌握BJT的H参数小信号模型及其简化
  • 掌握共射极放大电路的静态分析和动态分析
  • 掌握共集电极（射极跟随器）和共基极放大电路的特点
  • 理解FET与BJT及其基本放大电路性能的比较

5.1 双极结型三极管（BJT）

5.1.1 BJT的结构简介

半导体三极管有两种类型：NPN型和PNP型。三个电极：集电极（Collector）、基极（Base）、发射极（Emitter）。

结构特点：

  • 发射区的掺杂浓度最高
  • 集电区掺杂浓度最低，且面积大
  • 基区很薄，一般在几个微米至几十个微米，且掺杂浓度低于发射区

5.1.2 BJT的工作原理

三极管的放大作用是在一定的外部条件控制下，通过载流子传输体现出来的。

  • 发射区：发射载流子
  • 基区：传送和控制载流子
  • 集电区：收集载流子
放大条件：
(1) 内部条件：发射区杂质浓度远大于基区杂质浓度，且基区很薄。
(2) 外部条件：发射结正向偏置，集电结反向偏置。

载流子传输过程（以NPN为例）

发射结正偏 → 发射区向基区注入电子 → 基区中电子扩散到集电结边界 → 集电结反偏，内电场收集电子 → 形成较大的集电极电流。改变发射结正偏电压，则有不同的 iB 和 iE，从而导致不同的 iC。

控制关系

IC = α IE + ICBO
IE = IB + IC

通常 IC ≫ ICBO，α 为共基极电流放大系数，一般 α = 0.9~0.99。

IC = β IB + ICEO， β = α/(1−α)

β 为共射极电流放大系数，一般 β 为几十到几百。

由于三极管内有两种载流子（自由电子和空穴）参与导电，故称为双极型三极管或BJT（Bipolar Junction Transistor）。

三极管的三种组态

组态公共端输入输出电流关系
共基极(CB)基极发射极集电极iC = α iE
共发射极(CE)发射极基极集电极iC = β iB
共集电极(CC)集电极基极发射极iE = (1+β) iB

5.1.3 BJT的I-V特性曲线

共射极输出特性曲线的三个区域

区域条件特点
截止区vBE < 死区电压iC ≈ 0（iB = 0曲线下方）
放大区发射结正偏，集电结反偏iC = β iB，曲线平行等距，vBE≈0.7V(Si)/0.2V(Ge)
饱和区发射结正偏，集电结正偏或反偏电压很小iC明显受vCE控制，vCE＜0.7V(Si)

5.1.4 BJT的主要参数

  • 电流放大系数：共射直流电流增益 β，交流电流增益 βac（≈ β）
  • 极间反向电流：ICBO（集电结反向饱和电流）、ICEO = (1+β)ICBO（穿透电流）
  • 极限参数：ICM（最大集电极电流）、PCM（最大耗散功率）、V(BR)CEO（集射击穿电压）

5.2 BJT放大电路

5.2.1 基本共射极放大电路

静态工作点（Q点）估算：一般硅管 VBEQ = 0.7V，锗管 VBEQ = 0.2V，β 已知。

IBQ = (VCC − VBEQ) / Rb
ICQ = β IBQ
VCEQ = VCC − ICQ Rc

5.2.2 BJT放大电路的图解分析

直流负载线：vCE = VCC − iC Rc，与 iB = IBQ 的输出特性曲线交点即为Q点。

5.2.3 BJT的小信号模型（H参数模型）

H参数方程：

vbe = hie ib + hre vce
ic = hfe ib + hoe vce

四个H参数的物理意义：

  • hie（rbe）：输出端交流短路时的输入电阻
  • hfe（β）：输出端交流短路时的正向电流传输比（电流放大系数）
  • hre（μT）：输入端交流开路时的反向电压传输比（很小，10⁻³~10⁻⁴）
  • hoe（1/rce）：输入端交流开路时的输出电导（rce 很大，约100kΩ）

简化H参数模型

忽略 μT（很小）和 rce（很大），得到简化模型：

  • β ib 是受控源，且为电流控制电流源（CCCS）
  • 电流方向与 ib 的方向是关联的

rbe 的估算公式：

rbe = rbb' + (1+β) · VT/IEQ ≈ 200Ω + (1+β) · 26mV/IEQ

其中对于低频小功率管 rbb' ≈ 200Ω。

注意：H参数都是小信号参数（微变参数/交流参数），与工作点有关，只适合对交流信号的分析。不能用万用表"欧姆"档测量b、e两极之间的电阻来获得rbe。

5.2.4 共射极放大电路动态分析

电压增益：Av = vo/vi = −β(Rc ∥ RL) / rbe
输入电阻：Ri = Rb ∥ rbe
输出电阻：Ro = Rc

控制方式电压控制（VCCS），gmvgs电流控制（CCCS），βib
