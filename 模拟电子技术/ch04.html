4.1.1 N沟道增强型MOSFET

结构

L：沟道长度，W：沟道宽度，tox：绝缘层厚度。通常 W > L。

工作原理

（1）VGS对沟道的控制作用：

  • 当 VGS ≤ 0 时：无导电沟道，d、s间加电压时也无电流产生
  • 当 0 < VGS < VTN 时：产生电场，但未形成导电沟道（反型层），没有电流
  • 当 VGS > VTN 时：在电场作用下产生导电沟道，VGS越大，导电沟道越厚。必须依靠栅极外加电压才能产生反型层的MOSFET称为增强型器件

VTN 称为阈值电压（开启电压）。

（2）VDS对沟道的控制作用：

当 VGS > VTN 固定时，VDS ↑ → ID ↑ → 沟道电位梯度 ↑ → 靠近漏极d处的电位升高 → 电场强度减小 → 沟道变薄，整个沟道呈楔形分布。

当 VDS 增加到使 VGD = VGS − VDS = VTN 时，在紧靠漏极处出现夹断。夹断后，VDS ↑ → 夹断区延长 → 沟道电阻 ↑ → ID 基本不变。

关键结论：
  • 沟道中只有一种类型的载流子参与导电，所以场效应管也称为单极型三极管
  • MOSFET是电压控制电流器件（VCCS），iD受vGS控制
  • 预夹断前iD与vDS呈近似线性关系；夹断后，iD趋于饱和
  • MOSFET的栅极是绝缘的，所以iG≈0，输入电阻很高

I-V特性曲线及特性方程

（1）输出特性（三个工作区）：

工作区条件特性方程
① 截止区vGS < VTNiD = 0
② 可变电阻区vDS < vGS − VTNiD = Kn[2(vGS−VTN)vDS − vDS²]
③ 恒流区（放大区）vGS > VTN 且 vDS ≥ vGS−VTNiD = Kn(vGS − VTN)²

其中 Kn 为电导常数，单位：mA/V²。Kn = (μnCox/2)(W/L)。必须让FET工作在恒流区（放大区）才有放大作用。

（2）转移特性：在恒流区，iD 受 vGS 控制，iD = Kn(vGS − VTN)²。

4.1.2 N沟道耗尽型MOSFET

二氧化硅绝缘层中掺有大量的正离子，已存在导电沟道。可以在正或负的栅源电压下工作，而且基本上无栅流。vGS = 0 时就有 iD = IDSS（饱和漏电流）。

iD = IDSS(1 − vGS/VTN)²

注：对耗尽型NMOS，VTN < 0（夹断电压），所以 vGS 可以为正、零或负。

4.1.3 P沟道MOSFET

P沟道与N沟道的区别：

  • 衬底为N型半导体，掺杂形成P型源区和漏区
  • 恒流区条件：vGS < VTP（增强型VTP < 0），vDS < vGS − VTP
  • 电流以流入漏极的方向为正（实际方向与N沟道相反）

4.1.4 沟道长度调制等几种效应

  1. 沟道长度调制效应：当vGS固定、vDS增加时，沟道长度L变短，iD会有所增加。修正后 iD = Kn(vGS−VTN)²(1+λvDS)，λ = 1/VA，VA称为厄利（Early）电压
  2. 衬底调制效应（体效应）：衬底偏压vBS影响实际阈值电压。分立元件中衬底通常与源极相连（vBS=0）；集成电路中N沟道衬底接最低电位，P沟道衬底接最高电位
  3. 温度效应：VTN和Kn随温度升高而下降。VGS较小时温度升高iD增大，VGS较大时温度升高iD减小。这为功率MOS管的稳定运行提供了有利保障
  4. 击穿效应：漏衬击穿（漏源电压过高导致PN结击穿）和栅极击穿（绝缘层击穿，通常在栅源间接入双向稳压管保护）

4.1.5 MOSFET的主要参数

类别参数说明
直流参数VTN (VTP)阈值电压（增强型）
直流参数IDSS饱和漏电流（耗尽型，vGS=0时）
直流参数RGS直流输入电阻（10⁹～10¹⁵ Ω）
交流参数gm低频互导（跨导），gm = 2Kn(VGSQ−VTN) = 2√(KnIDQ)

极限参数IDM, PDM, V(BR)DS, V(BR)GS最大漏极电流、最大耗散功率、击穿电压

4.2 MOSFET基本共源极放大电路

4.2.1 基本共源极放大电路的组成

如何让MOS管工作在恒流区？VGG提供栅源电压使 vGS > VTN；VDD 和 Rd 提供合适的漏源电压，使 vDS > vGS − VTN。Rd 还兼有将电流转换成电压的作用。

信号由栅源回路输入、漏源回路输出，即源极是公共端，所以称此电路为共源电路。

4.2.2 基本共源极放大电路的工作原理

  • 静态：输入信号为零（vi = 0）时的工作状态，也称直流工作状态。FET的直流量 ID、VGS、VDS 在输出特性曲线上表示为一个确定的点——静态工作点Q（IDQ、VGSQ、VDSQ）
  • 动态：输入信号不为零时的工作状态。vGS = VGSQ + vi，iD = IDQ + id，vDS = VDD − iDRd

直流通路和交流通路：仅有直流电流流经的通路为直流通路；直流电压源对交流相当于短路，仅有交流电流流经的通路为交流通路。

静态工作点估算

假设NMOS管工作于恒流区，则：VGSQ = VGG，IDQ = Kn(VGSQ − VTN)²，VDSQ = VDD − IDQRd。

必须检验是否满足恒流区工作条件：VDSQ > VGSQ − VTN > 0。如果初始假设是错误的，则必须作出新的假设，同时重新分析电路。

4.3 图解分析法

4.3.1 用图解方法确定静态工作点Q

静态：vi = 0。输入回路 vGS = VGG = VGSQ；输出回路 vDS = VDD − iDRd（直流负载线）。负载线与 VGSQ 对应输出特性曲线的交点即为Q点。

4.3.2 动态工作情况的图解分析

vGS = VGSQ + vi，工作点沿负载线移动：vi ↑ → vGS ↑ → iD ↑ → vDS ↓ → |vds(vo)| ↑。vds与vi相位相反。

静态工作点对波形失真的影响

  • 截止失真（NMOS）：Q点过低，vGS在负半周低于VTN，管子进入截止区
  • 饱和失真（NMOS）：Q点过高，vDS在正半周小于vGS−VTN，管子进入可变电阻区

4.4 小信号模型分析法

4.4.1 MOSFET的小信号模型

建立小信号模型的意义：由于场效应管是非线性器件，分析起来非常复杂。建立小信号模型，就是在特定条件下将非线性器件做线性化近似处理，从而简化由其构成的放大电路的分析和设计。当放大电路的输入信号幅值较小时，就可以把三极管小范围内的特性曲线近似地用直线来代替。

小信号模型（λ ≠ 0 时）：

  • gmvgs 是受控源，且为电压控制电流源（VCCS）
  • rds 为d、s端口看入的输出电阻

参数物理意义

  • gm（低频互导/跨导）：转移特性曲线Q点上切线的斜率。gm = ∂iD/∂vGS|Q = 2Kn(VGSQ−VTN)
  • rds（输出电阻）：输出特性曲线Q点上切线斜率的倒数。rds = 1/(∂iD/∂vDS)|Q

模型应用的前提条件

  • 参数都是小信号参数（微变参数/交流参数），与静态工作点有关
  • 只适合对交流信号（变化量）的分析
  • 未包含结电容的影响，不能用于分析高频情况
  • 小信号条件：vgs ≪ 2(VGSQ − VTN)
  • 所有管型（增强型/耗尽型，NMOS/PMOS）模型相同，gm始终为正数

4.4.2 用小信号模型分析共源极放大电路

分析步骤：

  1. 求出电路的静态工作点（直流通路）
  2. 建立小信号等效电路（电容和直流电压源对交流相当于短路）
  3. 计算模型参数：gm = 2Kn(VGSQ−VTN)，rds = VA/IDQ
  4. 求动态指标
电压增益：Av = vo/vi = −gm(Rd ∥ rds ∥ RL)
输入电阻：Ri = Rg1 ∥ Rg2
输出电阻：Ro = Rd ∥ rds

4.4.3 带源极电阻的共源极放大电路

源极电阻 Rs 提供静态工作点稳定作用（反馈控制）：

假设温度变化导致 IDQ ↓ → VS ↓ → VGSQ ↑ → IDQ ↑（负反馈稳定过程）。

带源极电阻时电压增益降低：Av = −gmRd / (1 + gmRs)（忽略 rds）。

4.5 共漏极和共栅极放大电路

共漏极放大电路（源极跟随器）

信号由栅极输入、源极输出，漏极为公共端。

  • 电压增益：Av ≈ 1（略小于1），输出与输入同相
  • 输入电阻高（Ri → ∞，受偏置电阻限制）
  • 输出电阻低（Ro ≈ 1/gm）
  • 主要用途：缓冲/阻抗变换

共栅极放大电路

信号由源极输入、漏极输出，栅极为公共端。

  • 电压增益：Av ≈ gmRd（略小于共源放大），输出与输入同相
  • 输入电阻低（Ri ≈ 1/gm）
  • 输出电阻：Ro ≈ Rd

4.6 MOSFET大信号工作及开关应用

MOSFET在大信号下可作为电子开关使用。当 vGS > VTN 且 vDS 很小时，MOS管工作于可变电阻区（导通），相当于开关闭合；当 vGS < VTN 时，MOS管截止，相当于开关断开。功率MOSFET广泛应用于开关电源和电机驱动等场合。

4.9 各种FET的特性及使用注意事项

  • 栅极保护：MOSFET输入电阻极高，栅极悬空时可能因静电感应导致绝缘层击穿。通常在栅源间接入双向稳压管保护
  • 衬底连接：分立元件中衬底与源极相连（vBS = 0）；集成电路中N沟道衬底接最低电位，P沟道衬底接最高电位
  • VDS极性：NMOS的VDS必须为正（漏极为正），PMOS的VDS必须为负。极性接反会使PN结正偏，MOS管失效
