📌 说明

本页按章节顺序整理模拟电子技术课程中涉及的所有电路问题，每项包含：定义 → 产生原因 → 解决方法 → PPT来源。内容均基于PPT原文。

第1章 绪论

1.1 信号源内阻引起的输入信号衰减

原因：信号源内阻Rs与放大电路输入电阻Ri分压，vi=vs*Ri/(Rs+Ri)。Rs相对Ri不够小时信号被明显衰减。

解决：提高Ri，使Ri>>Rs。理想电压放大器Ri→∞。用共集/共漏跟随器作输入缓冲。

PPT来源：ch01 1.4 电压放大模型输入回路分析

1.2 负载对增益的影响

原因：输出电阻Ro与负载RL分压，vo=Avo*vi*RL/(Ro+RL)。RL不够大时vo明显小于开路电压。

PPT来源：ch01 1.4 电压放大模型输出回路分析

1.3 频率失真（线性失真）

定义：幅度失真——不同频率分量放大倍数不同；相位失真——不同频率分量时延不同。统称频率失真/线性失真。不产生新频率分量。

原因：电路中存在电抗元件（耦合/旁路电容、晶体管极间电容），阻抗随频率变化。

解决：①选用大耦合电容降低fL；②选高频特性好的晶体管提高fH；③引入负反馈展宽带。

PPT来源：ch01 1.5 4B.频率失真（线性失真）

1.4 非线性失真

定义：由元器件非线性特性引起的失真。产生输入信号没有的新频率分量（谐波）。非线性失真系数gamma=sqrt(sum(Vok^2))/Vo1, k>=2。

原因：晶体管iD-vGS（FET）或iC-vBE（BJT）特性不是理想直线，大信号下非线性显著。

解决：①限制输入信号幅度；②设置合适Q点在特性线性段内；③引入负反馈；④差分放大偶次谐波互相抵消。

PPT来源：ch01 1.5 5.非线性失真

第2章 运算放大器

2.1 开环运放无法直接用于线性放大

原因：开环增益极高（>=10^5），线性区对应差模输入仅约±0.1mV，极难稳定在线性区。且开环带宽很窄。

解决：引入负反馈，闭环增益稳定可控（Af≈1/F），同时大幅展宽带宽。

PPT来源：ch02 2.3.1 — "实际应用中，线性放大时都需要引入负反馈"

2.2 理想运放与实际运放的误差

原因：实际运放Avo有限（~10^5）、ri有限（~10^6Ω）、ro非零（~100Ω），与理想模型有差异。

解决：误差极小（约0.05%），而电阻本身容差±2%。PPT原文："用理想运放代替实际运放进行电路分析和设计完全可行。"

PPT来源：ch02 2.3.1 理想运放模型误差分析

第3章 二极管及其基本电路

3.1 温度对半导体导电性的影响

原因：温度升高→本征激发增强→载流子浓度升高→导电能力增强。PPT原文："本征半导体的电导率将随温度的升高而增加。"

解决：①留有热裕量；②温度补偿电路；③差分结构抵消漂移；④选用温度系数小的材料。

PPT来源：ch03 3.1 半导体的基本知识

3.2 PN结反向击穿

类型：雪崩击穿（载流子倍增效应，可逆）；齐纳击穿（强电场破坏共价键，可逆）；热击穿（过热烧毁，不可逆）。

解决：电击穿可逆，加限流电阻即可。齐纳二极管正是利用电击穿特性稳压。热击穿需限制功耗和电流。

PPT来源：ch03 3.2.3 PN结的反向击穿

3.3 PN结电容效应（限制高频应用）

原因：扩散电容CD（正向偏置时少子存储）+势垒电容CB（空间电荷区宽度变化）。高频时结电容阻抗降低，单向导电性变差。

解决：选用结电容小的点接触型二极管（高频检波/变频）；利用变容二极管的电容-电压特性实现压控调谐。

PPT来源：ch03 3.2.4 PN结的电容效应

3.4 二极管模型选择不当引起分析误差

原因：二极管是非线性器件，I-V特性为指数函数，直接使用不方便。

解决：按场景选模型——理想（大信号）、恒压降（最常用，Si=0.7V/Ge=0.3V）、折线（需更精确时）、小信号（仅交流小信号，需vD>>VT=26mV, rd=VT/IDQ）。

PPT来源：ch03 3.4.2 二极管电路的简化模型分析法

第4章 MOS场效应管及其放大电路

4.1 沟道长度调制效应

现象：vGS固定、vDS增加→漏端耗尽区向源端延伸→有效沟道变短→iD随vDS缓慢增大，饱和区曲线不水平。

影响：输出电阻rds有限（几十k~几百kΩ）。修正：iD=Kn(vGS-VTN)^2(1+lambda*vDS)，lambda=1/VA。

PPT来源：ch04 4.1.4 1.沟道长度调制效应

4.2 衬底调制效应（体效应）

原因：集成电路中衬底不接源极，vBS≠0→影响阈值电压VTH。N沟道衬底接最低电位，P沟道接最高电位。

解决：分立元件中衬底与源极相连（vBS=0）；IC设计中需考虑体效应对VTH的影响。

PPT来源：ch04 4.1.4 2.衬底调制效应

4.3 温度效应

现象：VTN和Kn均随温度升高而下降，Kn受温度影响更大。VGS较小时温度升高iD增大，VGS较大时温度升高iD减小。存在零温度系数点。

利用：功率MOS管在大电流下温度升高iD自动减小——"为功率MOS管的稳定运行提供了有利保障。"

PPT来源：ch04 4.1.4 3.温度效应

4.4 击穿效应

漏衬击穿：VDS过高→漏-衬PN结击穿。控制VDS在安全范围。

栅极击穿：绝缘层仅约50nm，约30V即可击穿（安全系数3时仅允许10V）。永久性损坏！

解决：栅源间接双向稳压管限制栅压；操作时防静电；存储时短接引脚。PPT原文："通常在MOS管的栅源间接入双向稳压管，限制栅极电压以保护器件。"

PPT来源：ch04 4.1.4 4.击穿效应

4.5 Q点不当→波形失真

截止失真：Q点过低→负半周vGS

饱和失真：Q点过高→正半周vDS进入可变电阻区→输出顶部削平。→减小ICQ。

稳定Q点：带源极电阻的偏置电路（反馈控制：IDQ↓→VS↓→VGSQ↑→IDQ↑）。

PPT来源：ch04 4.3.2 图解分析—Q点对波形失真的影响

4.6 VDS极性接反导致MOS管失效

PPT原文："VDS极性接反会怎样？PN结正偏，MOS管失效。"

原因：NMOS的VDS必须为正（漏极为正），PMOS的VDS必须为负。极性接反使漏极-衬底PN结正向偏置，产生大电流使管子失效。

解决：确保NMOS漏极接高电位/PMOS漏极接低电位；电路中加入防反接保护。

PPT来源：ch04 4.1.1 N沟道增强型MOSFET—VDS极性

4.7 偏置电阻降低栅极输入阻抗

PPT原文："受静态偏置电路的影响，栅极绝缘的特性并未充分表现出来。"

原因：MOSFET栅极本身绝缘（输入电阻极高，>10^9Ω），但外接偏置电阻Rg1//Rg2并联在栅极上，实际输入电阻Ri=Rg1//Rg2，远小于栅极本身电阻。

解决：偏置电阻与输入阻抗的折中——偏置电阻大→输入阻抗高但偏置受噪声干扰大；偏置电阻小→稳定但降低输入阻抗。

PPT来源：ch04 4.4.2 小信号模型分析共源放大电路—输入电阻计算

第5章 双极结型三极管及其放大电路

5.1 BJT温度敏感性

原因：ICBO每10度翻倍；VBE约-2mV/度减小；beta随温度升高增大。三者共同导致ICQ对温度极敏感，严重时可能热失控。

解决：①分压式偏置+射极电阻Re（直流负反馈稳Q）；②差分放大利用对称性抵消温漂；③选硅管（ICBO远小于锗管）。

PPT来源：ch05 5.1.4 BJT主要参数（自学）+ 5.2.1 Q点稳定

5.2 BJT Q点失真

同MOSFET，NPN和PNP失真方向不同：NPN共射底部失真=截止（ICQ太小，增大之）；NPN共射顶部失真=饱和（ICQ太大，减小之）。PNP极性相反。

解决：合理分压偏置使VCEQ≈VCC/2；射极电阻Re稳Q。

PPT来源：ch05 5.2.2 BJT放大电路的图解分析

5.3 射极电阻Re降低交流增益

PPT原文："放大电路的电压增益Av很小，只有1.05倍，其原因是发射极接入了电阻Re。在两端并联一个大电容可以消除Re的影响。"

原因：Re引入交流负反馈，使Av=(Rc//RL)/(re+Re)，增益大幅下降。Re越大，增益越低。

解决：在Re两端并联大电容Ce（旁路电容）——直流时Ce开路，Re起稳Q作用；交流时Ce短路Re，增益恢复为Av=(Rc//RL)/re。

PPT来源：ch05 5.2 放大电路分析—射极旁路电容的作用

第7章 模拟集成电路

7.1 零点漂移（零漂） 重点

定义：输入为零时，输出有缓慢变化的电压。直接耦合多级放大器中零漂被逐级放大，严重影响性能。

原因：温度→晶体管参数变化（VBE/beta/ICBO）→各级Q点漂移。PPT原文："温度变化和电源电压波动等效于共模信号。"

解决：差分放大电路——利用对称性，温度对两管影响相同（共模信号），双端输出时互相抵消。PPT原文："差分放大电路的最大特点是能有效抑制共模信号和零点漂移。"

PPT来源：ch07 7.2 差分式放大电路

7.2 共模干扰

来源：环境电磁干扰、50Hz工频、温度漂移、电源纹波。两输入端同时出现且大小相等相位相同。

解决：差分放大：差模放大（Avd大）、共模抑制（Avc小）。KCMR=|Avd/Avc|越大越好。增大尾电流源动态内阻RSS可提高KCMR。

PPT来源：ch07 7.2.1 MOSFET差分式放大电路—共模分析

7.3 运放输入失调电压/电流

定义：VIO—为使vo=0需在输入端加的补偿电压。IIO—两输入端偏置电流之差。PPT原文："由于失调电压、失调电流、偏置电流的存在使输出电压不为0。"

解决：①选低失调运放（OP07等）；②输入端加调零电位器；③交流耦合隔直；④自动归零技术。

PPT来源：ch07 7.5 运放主要参数

7.4 转换速率（SR）限制

定义：SR=dvo/dt|max，大信号下输出电压的最大变化速率。SR不足→正弦波变三角波。

选型准则：对给定Vom和fmax，需要SR >= 2*pi*fmax*Vom。

PPT来源：ch07 7.5 转换速率SR

第8章 反馈放大电路

8.1 自激振荡 重点

定义：负反馈放大电路在某些频率下，负反馈变正反馈，无输入时输出端产生固定频率和幅度的振荡。

条件：AF=-1（|AF|=1且附加相移180度）。PPT原文："当AF=-1时产生自激振荡。"

解决：①频率补偿——密勒电容将主极点移向低频，确保|AF|=1处附加相移<180度（相位裕度>0）；②RC串联补偿；③限制反馈深度；④减少放大级数。

PPT来源：ch08 8.6 负反馈放大电路的稳定性

8.2 反馈极性判断错误

后果：负反馈误判为正反馈→电路设计错误→不稳定甚至振荡。

正确步骤（PPT原文）：①先正确区分基本放大电路和反馈网络；②顺着信号传输方向逐级标注瞬时极性；③知道各种基本放大电路的相位关系；④正确确定反馈信号的引入位置。

PPT来源：ch08 8.1.3 正反馈与负反馈—瞬时极性法

8.3 深度负反馈近似计算存在误差

PPT原文："环路增益直接影响着误差的大小，环路增益越大，误差越小。注：此处忽略了频率变化导致A减小带来的影响。"

原因：深度负反馈近似公式Af≈1/F是在AF→∞的极限下得到的。实际AF有限，计算存在误差。当环路增益不够大时误差不可忽略。且高频时开环增益A下降，AF进一步减小，误差增大。

解决：①确保环路增益AF足够大（通常AF>=10时误差<10%）；②精确计算时使用完整公式Af=A/(1+AF)；③考虑频率对A的影响。

PPT来源：ch08 8.4 深度负反馈近似计算—4.近似计算带来的误差

8.4 反馈环内噪声干扰

PPT原文：负反馈可以"抑制反馈环内噪声"。

原因：放大电路内部元件会产生噪声（热噪声、散粒噪声等），这些噪声等效为环内干扰信号，被负反馈抑制。

注意：负反馈只能抑制反馈环内的噪声，对环外噪声（如输入端引入的噪声）无效。无噪声前置放大+负反馈是常用设计策略。

PPT来源：ch08 8.3.3 抑制反馈环内噪声

第9章 功率放大电路

9.1 甲类功放效率极低

原因：甲类导通角=360度，静态电流大且恒定。电源功率PV恒定，无信号时全部转化为管耗。最大理论效率仅25%（电阻负载）。

解决：改用乙类/甲乙类推挽——Q点近截止（ICQ≈0），两管各导通半周期。PPT原文："提高效率的主要途径：降低静态功耗，即减小静态电流。" 乙类理论最大效率78.5%。

PPT来源：ch09 9.1 输出级工作状态分类及提高效率的主要途径

9.2 乙类功放的交越失真 重点

现象：输入过零时|vBE|<死区电压（0.7V），两管均截止，输出电压在零点附近出现"平台"。

解决：改为甲乙类——给两输出管提供小静态偏流（微导通）。实现：①二极管偏置（两管基极间串两二极管≈1.4V）；②VBE倍增电路（一BJT+两电阻，可调稳定偏压）。

PPT来源：ch09 9.4 甲乙类互补对称功率放大电路

9.3 功率管二次击穿（不可逆损坏）

机理：大电流→发射极电流不均匀→局部热点→温度升高→VBE减小/beta增大→电流更集中→正反馈恶性循环→烧毁。不同于一次击穿（PN结雪崩，可逆）。

解决：①确保工作在SOA内；②加散热器降结温；③发射极镇流电阻均流；④选抗二次击穿能力强的功率管。

PPT来源：ch09 9.6 功率管

9.4 功率管散热不足

关系：Tj = TA + PT * theta_JA。热阻theta_JA（结到环境）限制散热。结温超过Tjmax→永久损坏。

解决：加散热器降热阻（theta_JC+theta_CS+theta_SA << theta_JA）；选低热阻封装；必要时风冷/液冷；设计留热裕量。

PPT来源：ch09 9.6 功率管—散热设计

第10章 信号处理与信号产生电路

10.1 滤波器特性不理想

问题：通带有纹波、阻带衰减有限、过渡带不够陡。

解决：①增加阶数n→过渡带更陡；②选逼近方式：巴特沃斯（通带最平坦）、切比雪夫（过渡带更陡有纹波）、椭圆（过渡带最陡）；③开关电容滤波器精确控制截止频率。

PPT来源：ch10 10.1 频率响应的逼近方式

10.2 正弦波振荡电路不起振或波形失真

不起振：|AF|<1或相位条件不满足。起振信号源=器件噪声+电源接通扰动。需|AF|>1（取1.1~1.3）。

波形失真：稳幅环节失效或输出幅度过大。解决：热敏电阻NTC、JFET压控电阻、二极管限幅。

PPT来源：ch10 10.5/10.6 正弦波振荡条件及RC振荡电路

10.3 比较器输出抖动

现象：单门限比较器在vi接近VTH时，因噪声叠加导致输出反复跳变（震颤）。

解决：施密特触发器（迟滞比较器）——引入正反馈，上下门限不同（VTH+≠VTH-），滞回宽度=VTH+-VTH-有效抑制噪声抖动。PPT原文："门限电压随输出电压变化"。

PPT来源：ch10 10.8 施密特触发器

10.4 有源滤波器频率和功率限制

PPT原文："优点：不用电感、体积小、重量轻，有一定的电压放大和缓冲作用。缺点：工作频率难以做得很高，不适宜大功率场合。"

原因：运放的增益带宽积有限，高频时开环增益下降，滤波特性恶化。运放输出电流有限，无法驱动大功率负载。

解决：①高频应用选用宽带宽运放或改用无源LC滤波器；②大功率场合用功率运放或无源滤波。

PPT来源：ch10 10.2 一阶有源滤波电路—有源与无源对比

10.5 集成比较器灵敏度不足

PPT原文："开环增益低、失调电压大、共模抑制比小，灵敏度往往不如用集成运放构成的比较器高。"

原因：专用集成比较器虽然速度比运放快，但开环增益和精度不如通用运放，输入失调电压和偏置电流较大。

解决：对精度要求高的场合（如精密电压比较），可用集成运放替代比较器（需注意运放从饱和恢复的速度）。

PPT来源：ch10 10.8 集成电压比较器
