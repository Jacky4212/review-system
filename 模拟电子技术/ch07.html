📌 教学基本要求

  • 掌握MOSFET和BJT镜像电流源、微电流源、多路电流源的原理
  • 掌握差分式放大电路的结构、工作原理和动态分析（差模/共模）
  • 理解共模抑制比KCMR的意义
  • 了解集成运算放大器的内部电路结构
  • 掌握运放的主要参数（输入失调电压/电流、共模抑制比、转换速率等）

7.1 模拟集成电路中的直流偏置技术

在模拟集成电路中，广泛使用电流源作为偏置电路和有源负载，以替代分立元件电路中的大电阻。

7.1.1 MOSFET电流源

1. 镜像电流源

T1、T2的参数全同。只要满足 VGS > VTN，必有 VDS1 > VGS − VTN，T1一定工作在恒流区。T2漏极接负载构成回路后，只要满足 VDS2 > VGS − VTN，就一定工作在恒流区：

IO = IREF · (W/L)2 / (W/L)1

IO的电流值与负载无关。负载在一定范围内变化时（保证 VDS2 > VGS − VTN），IO的电流值将保持不变，反映出IO的恒流特性。动态电阻（交流电阻）很大。

2. 多路电流源电路

除宽长比外，各管特性相同。通过设置不同的宽长比，可以从同一参考电流产生多个不同大小的输出电流。需保证所有管子工作在恒流区。

耗尽型MOSFET电流源

N沟道耗尽型管的夹断电压 VPN < 0。只需满足 VDS > −VPN 即可工作在恒流区。

7.1.2 BJT电流源

1. 镜像电流源

T1、T2的参数全同：

IO = IREF · (1 − 2/β)

当 β 很大时，IO ≈ IREF。动态电阻 ro 一般在几百千欧以上。

2. 微电流源

通过在T2发射极串联电阻 Re，可使 IO 远小于 IREF，产生微安级电流。

3. 多路电流源

T1、R1和T4支路产生基准电流 IREF；T1和T2、T4和T5构成镜像电流源；T1和T3、T4和T6构成微电流源。

7.2 差分式放大电路

7.2.1 MOSFET差分式放大电路

电路结构与基本概念

两个输入端：vi1、vi2；两个输出端：vO1、vO2。要能够放大直流——采用直接耦合。

与单端（共源）放大电路相比，差分放大电路的最大特点是能有效抑制共模信号和零点漂移。

差模信号 vid：两个输入端信号之差，vid = vi1 − vi2。差模信号大小相等、相位相反。
共模信号 vic：两个输入端信号的平均值，vic = (vi1 + vi2) / 2。共模信号大小相等、相位相同。

差模分析

根据对称性，差模输入时源极公共端为虚地（交流电位为零）：

双端输出差模电压增益：Avd = vod/vid = −gmRd
差模输入电阻：Rid = 2Ri（单端看入）
双端输出电阻：Ro = Rd1 + Rd2 = 2Rd

共模分析

共模输入时，两管电流同时增大或减小，源极公共端电位随之变化，相当于每个管子的等效源极电阻为 2RSS（RSS 为尾电流源内阻）：

双端输出共模电压增益：Avc = voc/vic ≈ 0（理想对称时）
单端输出共模电压增益：Avc1 ≈ −Rd / (2RSS)

共模抑制比

KCMR = |Avd / Avc|

或用分贝表示：KCMR(dB) = 20lg|Avd/Avc|。KCMR 越大，抑制共模信号的能力越强。温度变化和电源电压波动等效于共模信号，差分放大电路通过高KCMR可有效抑制这些干扰。

差分放大电路的分析方法：静态工作点分析与之前放大电路相同；动态分析时，利用叠加原理将差模和共模分开处理——这是差分放大电路分析的核心手段。

传输特性

差分放大电路的差模传输特性描述了输出电流（或电压）与差模输入电压的关系。小信号范围内近似线性，大信号时呈现非线性限幅特性。线性输入范围约为：|vid| ≤ 2Vov（Vov = VGS−VTN 为过驱动电压）。

7.2.2 BJT差分式放大电路

电路结构与MOSFET差分放大类似，分析方法相同。差模电压增益（双端输出）：

Avd = −β Rc / rbe

共模电压增益和共模抑制比的公式与MOSFET差分放大电路类似，关键参数是尾电流源的动态内阻。

7.2.3 差分式放大电路的传输特性

差模传输特性为双曲正切函数：ΔiC = IEE · tanh(vid/2VT)。小信号时（|vid| ≪ 2VT ≈ 52mV），特性近似线性。

7.4 集成运算放大器电路简介

典型CMOS集成运放的内部结构：

  1. 输入级：差分放大电路（通常为PMOS或NMOS差分对），提供高输入阻抗和高共模抑制比
  2. 中间级：共源放大电路，提供主要电压增益
  3. 输出级：一般为AB类互补输出级（源极跟随器/共漏放大），提供低输出阻抗和较大的输出电流驱动能力
  4. 偏置电路：电流源提供各级的直流偏置

通过相位补偿电容（密勒电容）保证运放的稳定性。
